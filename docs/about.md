# About SwitchcraftKeys

## The Developer

**Marcelo Frau** — Developer, Windows tinkerer, and keyboard layout enthusiast.

SwitchcraftKeys was born from the frustration of manually switching layouts every time I moved between my desktop and notebook keyboards. What started as a personal utility grew into a full-featured, open-source project.

- **Website**: [marcelofrau.com](https://marcelofrau.com)
- **GitHub**: [github.com/marcelofrau](https://github.com/marcelofrau)
- **Email**: marcelofrau@gmail.com
