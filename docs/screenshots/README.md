# Screenshots

Place application screenshots here to showcase SwitchcraftKeys features in README.md.

## Expected Images

- **dashboard.png** — Main window showing device list, layout selectors, reset buttons
- **tray-menu.png** — System tray icon context menu (Open, Minimize, Exit)
- **debug-overlay.png** — Debug overlay window with event log and device info
- **installer-wizard.png** — NSIS installer welcome screen (MUI2 wizard style)

## Guidelines

- **Format**: PNG or JPG (PNG preferred for sharpness)
- **Size**: Screenshots should be at least 1280×720px for clarity
- **Naming**: Use snake_case (e.g., `dashboard.png`, `debug-overlay.png`)
- **Themes**: Use Luna theme (light colors, soft blues/greens) for consistency

## How to Capture

1. Run the application: `SwitchcraftKeys.exe`
2. Take screenshots of:
   - Main dashboard with sample devices and layouts
   - Tray icon right-click menu
   - Debug overlay window (enable via dashboard)
   - Installer wizard (run `dist\SwitchcraftKeys-v*.exe`)

## Adding to README

Screenshots are referenced in README.md as:
```markdown
![Dashboard](docs/screenshots/dashboard.png)
```

After uploading images here, they will automatically appear in the README on GitHub.
